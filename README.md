# Mohamed Slimani — Engineering Portfolio

Static HTML, CSS and vanilla JavaScript portfolio hosted with GitHub Pages.

## Local preview

Serve the repository root:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

The five pages are Home, Resume, Projects, About and Contact. No build step or package installation is required.

## Editing

- `data.js`: 12 project case studies, conceptual drawings, project photo captions and coursework.
- `app.js`: project dialogs, category filters, experience timeline, navigation, coursework search and contact interactions.
- `style.css`: shared presentation and responsive layout.
- `index.html` and page directories: page text and structure.
- `assets/Mohamed-Slimani-CV.pdf`: the existing published CV.
- `PHOTO-SOURCES.json`: the mapping for previously supplied photos.
